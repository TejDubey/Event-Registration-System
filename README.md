# Event Registration System

A full-stack Event Registration System built with HTML, CSS, JavaScript, Node.js, Express.js, MongoDB Atlas, Mongoose, and bcrypt.

## Features

- User Registration
- User Login
- Password Hashing using bcrypt
- Duplicate Email Validation
- MongoDB Atlas Integration
- Responsive UI
- RESTful APIs

## Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- bcrypt
